Required asset files (copy from output/ or the existing submission build):

  mean_frame.npy        cohort mean frame used for phase-correlation alignment
                        source: output/cohort_mean_frame.npy  (generated by run_analysis.py)

  template_crop.npy     m4 crop of the mean frame, used for placement QC
                        generate with:
                          import numpy as np
                          from src.preprocess import crop_slices
                          mean = np.load("assets/mean_frame.npy")
                          crop = mean[crop_slices(margin=4)]
                          np.save("assets/template_crop.npy", crop)

Both files must be present before zipping for submission.
